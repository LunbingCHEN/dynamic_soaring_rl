# Step-Level Dynamic Soaring Project Website

GitHub Pages source for:

<https://lunbingchen.github.io/dynamic_soaring_rl/>

## Purpose

This project website presents *Learning step-level dynamic soaring in shear flow* as both a scientific contribution and evidence of research capability in:

- fixed-wing flight dynamics;
- reinforcement learning and feedback control;
- environmental-energy flight;
- autonomous UAV implementation.

The page complements, rather than duplicates, the main academic portfolio at <https://lunbingchen.github.io/>.

## Files and assets

- `index.html`: complete static project page.
- Research figures are loaded from the main portfolio repository at `https://lunbingchen.github.io/figures/` to avoid maintaining duplicate deployment copies.
- Videos are embedded from YouTube.
- The preprint is linked through DOI/arXiv.

## Local preview

From this directory:

```bash
python3 -m http.server 8001
```

Then open <http://localhost:8001/>.

## Deployment

GitHub Pages publishes the `main` branch of `LunbingCHEN/dynamic_soaring_rl` under the account site path `/dynamic_soaring_rl/`.

Before pushing, verify:

1. desktop and mobile layouts;
2. links to the preprint, videos, CV, and personal website;
3. remote figure URLs from the main portfolio repository;
4. publication status and author list.
